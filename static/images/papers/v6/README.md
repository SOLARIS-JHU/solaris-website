# SOLARIS graphical abstracts — revision 6

Approved collection prepared on 2026-11-06 for 39 SOLARIS publications.

Each paper has a PNG card preview, an animated vector SVG, and a static vector SVG. The Papers page loads animations only when a reader opens a graphical abstract. Reduced-motion readers receive static artwork until they explicitly choose to play it.

All visible artwork text is LaTeX rendered into native paths. The illustrations explain mechanisms and are not reproduced experimental data. Robot motion is representative planar kinematics; CINOC uses a separately computed forced-heat example with prescribed agent formations and synthetic inputs. QP curves and displayed iterates derive from documented numerical examples. Source details and scientific scope appear with each paper in the publication data.

The building-thermal benchmark graphic uses accessible abstract-level evidence without comparative rankings. Retain that limited-evidence scope when revising it.

Regeneration uses the revision 6 Python source collection retained with the authoring deliverables. These production assets require no external fonts or runtime image service.
